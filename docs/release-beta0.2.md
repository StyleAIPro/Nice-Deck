# AICO-PPT beta0.2

包内版本：0.1.37。

- 局部编辑按任务范围提供上下文，复用截图与统一编辑事务；跨页撤销/重做定位到实际修改页。
- 框选、标注与无关任务增删不再触发 Deck 内容版本冲突；真实内容变化和当前任务变化仍受保护。
- 区分 Creation Draft、编辑器与断开状态；初稿发布沿用当前轮回执，避免重复启动与重复自动制作消息。
- 私有 Python 可再生字节码不纳入运行时完整性比较，避免重复加载误报损坏。
- 局部片段编号拒绝明确报告未提交与缺失/重复编号；保留撤销历史和真实冲突检查。
- 五套模板统一“开始”导航；编辑工具内嵌已登记的图片附件，提交前验证加载与解码，坏图回滚并显示页码/资源。
- 修复删空富文本片段、DOM 重建后的重复重放误报；只在已提交且内容完全一致时跳过重复应用。

2026-10-16 回归：Editor Node 773 通过、3 跳过；DSH 接口 50 通过、2 跳过；Python 227 通过、9 跳过；真实浏览器撤销重做、图片资源、文本重放 40 项全部通过。原装安装验证与各修复范围见 verification-0.1.32–0.1.37.md。

## 安装与升级

Windows x64；原装 DSH Desktop 2.0.13 / DSH 0.1.5-rc.2。从[官网安装页](https://openx.huawei.com/project/7665/AICO-Plugin-Web_master/install.html)下载每个插件的完整包，核对 SHA-256，在原装托盘 DSH Terminal 中使用 `dsh plugin add "实际下载路径" --ignore-scripts` 安装。先 Harness，后所需业务插件；保存工作，从系统托盘完全退出并重新打开 Desktop。

beta0.1 用户需要先手动升级 Harness 一次，之后才具有各插件的在线新版本提醒；提醒引导去官网安装，不自动安装或重启。历史 beta0.1 标签、附件和用户业务数据保留。WSL 仅用于模型通信，业务及工具仍在 Windows，macOS 暂缓。
