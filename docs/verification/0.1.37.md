# 0.1.37：编辑态删字后的历史重放冲突

2026-10-16。修改仅涉及 AICO-PPT 的补丁运行时；原装 DSH、DSH Desktop、Harness 和用户 Deck 没有改动。

## 真实现场与原因

用户在 13 页 Deck 的第 10 页看到 `历史重放冲突：TARGET_AMBIGUOUS`，随后“固化修改”成功。只读检查确认源文件与工作副本 SHA-256 一致，当前历史为空，33 条任务和三次固化历史归档保留。

使用固化前备份及最近归档中的四条人工动作，在隔离副本复现同一个错误；失败定位到最后一条细粒度删字动作。最小场景仅需一个带 `span`／`strong` 的文本框：删除整个文字节点，再恢复祖先 `innerHTML`。空节点会在 HTML 往返中消失；旧逻辑尝试再次定位已删空的片段，报 `TARGET_AMBIGUOUS`。即使不重建，空节点被文本遍历过滤后也可能报 `TARGET_NOT_FOUND`。保留一个字符则不报错，且不经过固化也能复现，因此故障在浏览器历史重放，并非此次固化写盘失败。

## 修复范围

- 成功提交后，以动作对象为弱引用键保留完整目标内容及动作目标／文本证据；只在同一节点或持久编号对应的唯一节点、完整 `innerHTML` 未改变时，识别为已经应用并跳过重复删字。
- 多动作以提交后的最终状态记录，未提交／回滚不更新证据；不向用户历史增加字段，不信任外部请求中的空 `after`。
- 真实内容被替换、没有运行时证据、目标编号重复或丢失，继续执行原来的冲突保护。撤销、重做、固化继续使用原有权威历史。
