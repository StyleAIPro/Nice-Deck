# 0.1.38：页码栏键盘与滚轮切页

2026-10-16。仅修改 AICO-PPT，使用原装宿主接口；按用户要求只生成插件包与安装命令，不安装插件、不重启 Desktop。

## 行为

- 点击左侧页码后，↑／↓ 切换上一页／下一页；在页码栏滚动滚轮也可逐页切换。
- 展开与收起均支持，焦点跟随切换目标，选中页码自动滚入列表可见区域。只调整列表滚动位置，不带动整个工作台。
- 首尾停留、不循环。触控板小增量合并，连续滚动限速；一次大滚动最多切一页。
- 焦点离开页码栏后不拦截滚动；编辑文字、横向滚动、带 Ctrl／Cmd 等修饰键的操作保持原有用途。切页仍经原有 frame 确认，不直接改写业务历史。
