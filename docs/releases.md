## 公开渠道与升级

[官方安装页](https://openx.huawei.com/project/7665/AICO-Plugin-Web_master/install-official.html)提供正式下载；公开清单由官网仓维护，见工作区中的 `AICO-Plugin-Web/current-official.json` 与 本次 `beta0.4.json` 及历史 `beta0.3.json`。正在准备的新标签只有在附件上传、匿名下载及摘要核验完成后才推进指针。

通过原装“插件 → 添加插件”安装完整 Windows 包，先 Harness 后业务插件；保存工作与草稿，按原装结果决定是否重启。每个已发布标签和附件保持不可变，后续修订使用新版本。旧社区清单与官方清单隔离，不能用旧更新源推送官方包。

公开 Beta、登录成功及组件测试不等于最终四包在同一 Windows 工作区完成本机／WSL 模型、流式取消、Windows 工具、真实业务、共存及卸载联合验收。生产签名渠道与 macOS 仍未交付。

## 历史 beta0.2 变更与证据

以下只记录 2026-10-16 的历史包范围，不作为当前安装步骤或当前代码完整测试结论。

包内版本：0.1.37。

- 局部编辑按任务范围提供上下文，复用截图与统一编辑事务；跨页撤销/重做定位到实际修改页。
- 框选、标注与无关任务增删不再触发 Deck 内容版本冲突；真实内容变化和当前任务变化仍受保护。
- 区分 Creation Draft、编辑器与断开状态；初稿发布沿用当前轮回执，避免重复启动与重复自动制作消息。
- 私有 Python 可再生字节码不纳入运行时完整性比较，避免重复加载误报损坏。
- 局部片段编号拒绝明确报告未提交与缺失/重复编号；保留撤销历史和真实冲突检查。
- 五套模板统一“开始”导航；编辑工具内嵌已登记的图片附件，提交前验证加载与解码，坏图回滚并显示页码/资源。
- 修复删空富文本片段、DOM 重建后的重复重放误报；只在已提交且内容完全一致时跳过重复应用。

2026-10-16 回归：Editor Node 773 通过、3 跳过；DSH 接口 50 通过、2 跳过；Python 227 通过、9 跳过；真实浏览器撤销重做、图片资源、文本重放 40 项全部通过。原装安装验证与各修复范围见 verification-0.1.32–0.1.37.md。

历史开发包 `0.1.30`–`0.1.37` 的重复安装命令已移除。其有效修复包括编辑上下文／并发边界、Creation Draft 与发布回执、私有 Python 可再生缓存、局部片段编号、图片内嵌及删空富文本重放；对应检查保留在验证目录。旧 Deck 的错误图片路径需重新选择并内嵌后保存，升级不会自动改写用户 Deck；自定义导航继续保留。
