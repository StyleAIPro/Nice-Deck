# 快捷键

## Editor

| 快捷键 | 作用 |
|---|---|
| `Cmd/Ctrl + Z` | 撤销最近一次 Deck 修改 |
| `Cmd/Ctrl + Shift + Z` | 重做 |
| `Ctrl + Y` | Windows 重做 |
| `Cmd/Ctrl + S` | 保存受控检查点，不发布真实 Deck |
| `Cmd/Ctrl + Enter` | 提交当前文字编辑 |
| 按住 `R` | 在编辑与区域标记间临时切换 |
| `Esc` | 取消当前输入，或中断正在运行的 Agent 批次 |

输入框聚焦时，撤销快捷键优先作用于输入内容，不触发 Deck 全局历史。

## Deck 放映

| 快捷键 | 作用 |
|---|---|
| 空格 / `→` / 向下滚 | 前进一个节拍 |
| `←` / 向上滚 | 后退一个节拍 |
| `Cmd/Ctrl + 滚轮` | 缩放 slide canvas |
| `Cmd/Ctrl + +/-` | 缩放 slide canvas |
| 放大后按住空格 | 临时抓手拖动 |
