# 修改现有 Deck

## 适用场景

已经有 Huawei Deck 单文件 HTML，希望继续调整内容、格式、页面结构或动画。

## 操作步骤

1. 在首页“修改已经写好的 deck”卡片右下角点击加号。
2. 使用系统文件选择器选择一份 HTML。
3. 检查自动识别的 Agent 项目目录；范围过宽时改选更小的项目目录。
4. 选择 Agent 并打开编辑器。
5. 普通文字、移动、缩放和删除可在编辑模式直接操作；从红框边缘点选整个元素后按 `Delete` / `Backspace` 删除，复杂结构和动画交给右侧 Agent。
6. 使用撤销/重做核对修改，必要时在任务 drawer 查看未完成项。
7. 点击“固化修改”并通过验证后，结果才写回真实 HTML。

## 文件安全

Editor 会把真实 Deck 复制到 `.huawei-deck-editor` 中的托管工作副本。预览、自动保存和 Agent 修改都不会直接覆盖源文件。固化发生冲突或验证失败时会明确停止。

## 完成标志

顶栏没有未处理冲突，固化成功，并且重新打开源 HTML 可以看到最终结果。
