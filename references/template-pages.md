# template-pages.md — 34 页模板逐页索引

**先用浏览器打开 `assets/template-deck.html` 从头滚一遍，再回来查这张表。** 模板的占位文案本身就是「这一栏该写什么」的说明书：每个占位都在告诉你此处内容的写法、长度与语气；动画机制页（第 14–18 页）的正文更是直接讲解 build / layer / SMIL 的写法，边看边学。「05 · 完整示例」章（第 22–31 页）取自一门真实课件：不是占位骨架，而是版式填入真内容后的成品——eyebrow 保留原课程编号并统一加「示例 ·」前缀，复用时把正文与图换成你的内容即可。

拍数的通用规律：**拍数 = 页内最大 `data-step` + 2**（进页空场算第 0 拍，讲完再多点一次翻页）。调节拍 = 改 `data-step` 编号，详见 `animation.md`。

**复制某页做多页**的通用做法（详见 `editing-guide.md` 第 3 节）：用 `edit-bundle.py` 取出该页的整块 `<div class="slide-fit">…</div></div>`，把 `data-label` 改成新名字，再 `insert_page(s, 新块, before_label='目标位置页', nav_code='两字码', nav_label='新页名')`——DOM / 导航 / 章节起点三处同步它自动做完。⚠ 复制**封面 / 目录 / 章扉页 / 结语页 / 问题页 / 研讨页 / 两个黑板页**时注意：这些页的背景画、黑板底图、人像装饰是靠 `<style id="tpl-bg-950">` 里**按 data-label 精确匹配**的 CSS 规则挂上去的，新 label 要在该样式块里补一个选择器（如把 `section[data-label="章扉页"]` 的规则加上 `, section[data-label="章扉页2"]`），否则新页没有背景。

## 01 · 门面页型（页 0–4）

### 0 · 封面（1 拍）
- **长什么样**：金色背景画铺满，居中超大主标题 + 红色副标题条，底部主讲人 / 团队 / 口号三行。
- **常用于**：整个 deck 的第一页，一份 deck 一张。
- **怎么改**：全是文本占位——主标题、副标题、主讲人行、团队行直接替换；口号占位（「在此替换口号…」）按 `branding.md` 第 3 节的方式经 `edit-bundle.py` 替换（封面与结语页共 2 处，一次换完）。背景画整体替换用 `apply_bg.py --target bg`。

### 1 · 目录（1 拍）
- **长什么样**：金色背景画上叠一张目录卡，四章各一行：章号 + 章名 + 一句章描述 + 关键词 chips。
- **常用于**：课程 / 分享的章节总览。
- **怎么改**：**条目不在页面 HTML 里**，而在运行时脚本的 `const TOC = [...]` 与 `const tocChips = [...]` 两个数组中（在 template 字符串里直接搜 `const TOC`），改数组即可增删章条目。章数变化时记得同步导航的 `chapters[]`（见 `editing-guide.md`）。
- **⚠ 左侧章节动画要跟着章数走**：选中某章时左卡展示的动画由 `const builders = [animNN, animAlgo, ...]` 按**章节索引**取用（搜 `const builders`）——增删章后必须同步这个数组，否则新增章选中时左侧一片空白。现有 5 个动画函数（animNN / animAlgo / animMethod / animTF / animInfra）可按各章主题重新映射、不够就复用；同时检查各动画里的文字标注（`<text>` 内容与驱动数组）是否还匹配新主题，不匹配就替换成本 deck 的主题词——动画是章节的「核心意象」，文案跑题比空白更误导。

### 2 · 议程页（1 拍）
- **长什么样**：白卡内左侧一枚同心圆「靶心」装饰（带 SMIL 缓动，不占节拍），右侧四行课程目标，每行「目标句 + 章名 + CH.0X · 时长」。
- **常用于**：开场讲课程目标、章节安排与时间预算。
- **怎么改**：四行目标全是文本占位，逐行替换；增删行就复制 / 删除一个 `display:flex` 行块（注意首末行没有上下边框，中间行有）。左侧 SVG 是纯装饰，不用动。

### 3 · 章扉页（1 拍）
- **长什么样**：金色背景画，左上超大半透明章号水印「01」，`SECTION 01 · XX MIN` 小标签，100px 章名，两三句章副题，底部一排小节关键词胶囊。
- **常用于**：每章开头一张。**这是最常需要复制成多页的页型。**
- **怎么改**：章号出现在水印和 SECTION 标签两处，别漏改；关键词胶囊按需增删 `<span>`。复制成第 2/3/4 章扉页时按本文开头的复制流程操作，并给新 label 补 `tpl-bg-950` 选择器（背景画规则按 data-label 精确匹配）。

### 4 · 问题页（1 拍）
- **长什么样**：右上超大半透明「Q1」水印，72px 大问题一行（关键词标红），右下角人像装饰（由 `tpl-bg-950` 的 `::after` 规则挂上）。
- **常用于**：每章 / 每节开场抛一个真问题，引发讨论后再进入内容。
- **怎么改**：改题干文本与「Q1」编号即可；提问不给答案（引导思考是这一页的本职）。复制成 Q2/Q3 时同样注意给新 label 补 `tpl-bg-950` 的 `::after` 选择器，否则人像不出现。人像图整体替换用 `apply_bg.py --target people`。

## 02 · 内容版式（页 5–13）

### 5 · 版式·卡片网格（6 拍）
- **长什么样**：上半部一排名词卡 + 一张红边「视频卡」（外部链接示例），下半部五个概念自外向内逐层包含、逐拍点亮的解释块。
- **常用于**：讲一组名词的层级 / 包含关系；页面上挂一个外部视频入口。
- **怎么改**：名词卡与概念解释块都是文本占位；五个解释块 `data-step="0"…"4"` 依次出现，减少概念数就删块并重排编号。视频卡把 `href="https://example.com/your-video-link"` 换成真实链接——**贴 bilibili 视频链接（含 `/video/BV…`）会被运行时自动接管，点开直接弹内嵌播放器**，无需写任何 JS。

### 6 · 版式·左图右文（3 拍）
- **长什么样**：左栏一组「图占位 + 子项说明 + 类比行」的竖排卡，右栏两张图文卡；两栏分组小标题各带 mono 标签。
- **常用于**：一个主概念拆成几个子项，每个子项配小图和生活化类比。
- **怎么改**：虚线「图 · 占位」框换成真图（`embed_image` 嵌入后 `<img src="返回的uid" style="width:100%">`，见 `editing-guide.md`）；右栏两卡 `data-step="0"/"1"` 两拍出现，左栏进页即显示。

### 7 · 版式·流程条（5 拍）
- **长什么样**：顶部一张全宽图占位，下面四个步骤条（01–04），每条「步骤名 + 一句说明 + 🍲 类比行」，逐拍出现。
- **常用于**：讲一条 3–5 步的流程 / 管线，每步配同一场景延续的类比。
- **怎么改**：步骤条是文本占位，`data-step="0"…"3"` 与讲解顺序一致；加一步就复制一条并顺延编号（拍数自动 +1）。

### 8 · 版式·对比两栏（3 拍）
- **长什么样**：上下两组「旧方案 → 新方案」对比行，每组一句结论 + 支撑句 + 左右两张图占位（各带图注）。
- **常用于**：技术演进对比、方案 A/B 取舍，一页讲两组。
- **怎么改**：两组各挂 `data-step="0"/"1"` 整行整行出现（外层框也在 build 里，符合「背景框也挂 build」铁律）；只讲一组就删掉下排并把拍数减一。

### 9 · 版式·密集多栏（6 拍）
- **长什么样**：左侧一张双单元累计 / 汇总示意图（SVG + 卡片混排），右侧「人工指定参数」与「自动反算推导量」两张纵列卡，公式条与推导卡逐拍联动出现。
- **常用于**：一页塞下一组相互关联的参数 / 公式推导，信息密度最高的版式。
- **怎么改**：15 个 build 元素共用 `data-step="0"…"4"` 五拍——**同一 data-step 的多个元素同拍齐现**，这页是「一拍点亮一组」的范例；替换数字时保持左图与右卡的数值一致。密集页改完务必跑 `measure_overflow.mjs` 防溢出。

### 10 · 版式·表格混排（11 拍）
- **长什么样**：左列上下两卡（维度表格 + 双截图），右侧一张大业务流程图（SVG 节点连线 + 编号），底部步骤说明 1–7 逐条出现，末行相关工具链接。
- **常用于**：讲一套带角色 / 系统 / 环节的业务流程，配表格与截图佐证。
- **怎么改**：`data-step="0"…"9"` 共 11 拍，节奏是「左卡 → 截图 → 流程图 → 逐条步骤说明」；步骤说明的编号徽标与图中节点编号对应，改图时同步。嫌拍数多就把相邻说明合并到同一 data-step。

### 11 · 版式·全幅大图（1 拍）
- **长什么样**：标题下整页一张全幅 SVG 架构图：起点 → 阶段 → 分支 → 分层展开的树状结构。
- **常用于**：全景图 / 技术地图 / 体系结构，一页一图讲十分钟。
- **怎么改**：直接改 SVG 里的节点文字与连线；想逐层揭示就给各层 `<g>` 加 `class="build" data-step="N"`（注意 SVG 元素带 transform 时把 transform 放到非 build 的外层 `<g>`，见 `animation.md` 铁律）。

### 12 · 版式·截图对照（1 拍）
- **长什么样**：顶部关键指标卡（V1/V2 大数字 + 提速结论）与对照条件卡，中部两张截图占位并排，底部端到端 / 分阶段两张数据表。
- **常用于**：性能对比、实验前后对照——用真实截图 + 硬数字说话。
- **怎么改**：截图占位换真图（保留截图原生配色，别强行改色）；表格行直接增删 `<tr>`；结论数字（如 `1.76`）在标题、指标卡、表格里共出现 4 处，改时在该页片内全局搜索替换、逐处核对。

### 13 · 版式·动手实验（1 拍）
- **长什么样**：操作指引一行 + 全页 iframe 内嵌一个公开网页工具（模板嵌的是 TensorFlow Playground）+ 链接条与「复制链接」按钮。
- **常用于**：课堂动手环节，让听众当场打开同一工具操作。
- **怎么改**：换 iframe 的 `src` 和链接条文字即可；保留 `loading="lazy"`（性能）与复制按钮的 `class="copylink"`（复制逻辑由运行时事件委托接管，**不要**写内联 `onclick`，会触发 React #231）。部分站点拒绝被 iframe 嵌入（X-Frame-Options）时页面留白，复制链接按钮就是兜底。

## 03 · 动画机制（页 14–18）——这五页既是页型也是活教材

### 14 · 动画·build逐步（6 拍）
- **长什么样**：五张卡片带箭头连成一条推导链，`data-step="0"…"4"` 逐拍出现；每张卡上印着自己的 data-step 值。
- **常用于**：逐步揭示类讲解的骨架；也是学 build 机制的第一页。
- **怎么改**：照正文说明改：加卡 = 复制一张卡并顺延 data-step；同拍齐现 = 两元素写同一个 data-step。

### 15 · 动画·layer切换（5 拍）
- **长什么样**：四个标签按钮（组 `opt`）互斥切换四个面板，右侧配图；末拍一条 build 结论卡压轴，演示「layer 与 build 共享 level」。
- **常用于**：一个区域多状态切换（tab / 方案切换 / 阶段视图）。
- **怎么改**：按钮与面板按 `data-layer-btn` / `data-layer-panel` 同 key 同组配对；首个按钮**不写** data-step（默认显示），其余 0,1,2… 递增。加减标签后按此规则重排编号，规则详见 `animation.md`。

### 16 · 动画·混合链（8 拍）
- **长什么样**：五个 STEP 标签（组 `lora`）+ 面板内矩阵图，其中 STEP 4 面板内再嵌 3 个 build——layer 切换与面板内逐条出现串成一条 8 拍点击线。
- **常用于**：既要整版切换又要版内逐条揭示的复杂讲解。
- **怎么改**：先在纸上排好整条节拍线（哪拍切面板、哪拍出条目），再统一编 data-step——面板内 build 的编号要接在其所属标签编号之后。「先排拍后编号」方法见 `animation.md`。

### 17 · 动画·SMIL运动（2 拍）
- **长什么样**：SVG 图内 21 个 SMIL 动画标签（`<animate>` / `<animateTransform>`）驱动光带扫过与节点变色（循环播放、不占节拍）；旁边演示「build 覆盖卡盖住静态底卡」的同格堆叠替换。
- **常用于**：需要持续动效的示意图（数据流、信号传播）；SMIL 与 build 并存的写法参考。
- **怎么改**：SMIL 动画写在 SVG 元素内部，`repeatCount="indefinite"`，随页面激活自动播放、离页自动冻结，无需任何 JS；改图形时保留 `<animate>` 标签结构即可。

### 18 · 动画·多组切换（6 拍）
- **长什么样**：三栏——左「底图 + build 叠加图」（两张叠加图随节拍先后盖到常驻底图上），中 vffig layer 组（面板按钮挂 data-step，切换并入 build 点击线）+ 一张纯文字 build 卡，右 tl 组四个面板按钮（不挂 data-step）。
- **常用于**：一页需要两个独立切换区，或「先按节拍讲完 build、再自由切换面板」的复杂页；也是学多组 layer 的活教材。
- **怎么改**：照页面正文说明改；按钮挂 data-step 的组并入 build 点击线，不挂的组在 build 走完后接管后续点击。⚠ 「接管」逻辑在运行时脚本里按 `data-label === '动画·多组切换'` 精确匹配（共 3 处判断），复制此页改 label 时要在 template 字符串里同步改那 3 处，否则新页 build 走完后点击会直接翻页而不是切面板。

## 04 · 深色与黑板（页 19–21）

### 19 · 深色·金句（4 拍）
- **长什么样**：深底（#15171c）页面，「已经掌握」卡 → ⇒ → 「接下来要解决」红框卡 → 底部红底金句条，三拍递进；右下半透明章节号水印。
- **常用于**：章节间承上启下：小结前文、抛出缺口、金句收束。
- **怎么改**：全文本占位；三拍递进（data-step 0/1/2，⇒ 箭头与红框卡同拍）就是讲稿顺序；金句条上半句白字、下半句金字（#ffe08a）的强调结构保留。

### 20 · 黑板·题卡A（11 拍）
- **长什么样**：金框黑板底图上五张题卡（选择 + 填空混排），题干先出、答案后出，`data-step="0"…"9"` 共 11 拍——「出题 → 学生答 → 亮答案」的课堂节奏。
- **常用于**：章末课堂巩固测验。
- **怎么改**：题干 / 选项 / 答案全是占位文本；每题两拍（题卡一拍、答案一拍），删题记得重排后续编号。黑板底图整体替换用 `apply_bg.py --target board`；复制此页改 label 时需给新 label 补 `tpl-bg-950` 的黑板背景选择器。

### 21 · 黑板·金框题卡（9 拍）
- **长什么样**：同款金框黑板，另一种卡风：四题竖排、金色（#f4c84a）题号与徽标、答案行金字，`data-step="0"…"7"` 共 9 拍。
- **常用于**：题量较少（4 题内）、选项较长的巩固页；与题卡A 换着用避免视觉重复。

## 05 · 完整示例（页 22–31）——真实课件成品，即拿即改

这一章 10 页取自一门真实的昇腾大模型训练课：展示前面各版式填入真内容后长什么样。复用方法统一是「正文与图替换为你的内容」，下面只写每页的看点与特有改法。

### 22 · 实例 MNIST（6 拍）

### 23 · 梯度下降（6 拍）
