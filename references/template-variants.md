# template-variants.md — 技术分享与工作汇报两套模板变体

`assets/` 下共三套模板 deck，同一套设计系统与工具链（edit-bundle / verify / html2pptx 全部通用），**按场景选起点**：

| 场景 | 模板起点 | 页数 / 章 |
|---|---|---|
| 授课 / 培训 | `template-deck.html`（34 页全量画廊，含黑板 / 研讨 / 动画全集） | 34 页 · 6 章 |
| 技术分享 | `tech-share-deck.html` | 25 页 · 5 章 |
| 汇报 / 述职 / 方案评审 | `work-report-deck.html` | 22 页 · 5 章 |

变体从课程模板派生：去掉课堂专属页（黑板题卡 / 研讨）与课程用语（「敲黑板」类表达换成小结 / Takeaway），新增业务页型。所有新页占位文案沿用「画廊即文档」风格——占位文字本身在教这一栏怎么写；标题占位均示范「标题即观点、点名技术」句式。逐页改法通用规则同 `template-pages.md`（复制页 / 增删页 / data-label 定位）。

## 变体维护注意

- 两套变体的 TOC 左侧动画文案已中性化 / 场景化（PDCA、交付通路等）——再改主题时按 `template-pages.md` 目录页一节同步 `builders` 数组与动画文字。
- 汇报模板刻意不含动画页与研讨 / 黑板页（场景适配表纪律）；PPTX 常是硬要求，初版就试 `convert.sh`。
- 已知基线同课程模板：「版式·左图右文」自带 3 处占位框裁切提示，换真图后消失。
